01 Featured design

API-driven fan control for a datacenter GPU

Problem
The Tesla P4 is passive — built for datacenter airflow. A custom 3D-printed fan fixed the cooling, but passing the GPU through to the PelerServer VM meant the Proxmox host could no longer read its temperature.
Constraint
The sensor lives inside the VM; the fan controller lives on the host. Neither side can see the other’s half.
Solution
A decoupled control loop. A custom API on the host drives the DIY fan, while a script inside the VM monitors GPU temperature and calls the API.
Outcome
Real-time, temperature-aware fan speed across the virtualization boundary.
  • Proxmox
  • GPU passthrough
  • REST API

02 Quality of life

Remote lighting control via SSH X11 forwarding

Problem
Chassis RGB on an ROG motherboard needs vendor software — unavailable on a headless Linux host.
Solution
After trying many open-source drivers, OpenRGB ran on the host. SSH X11 forwarding launches its GUI from a laptop.
Outcome
All chassis lighting is controlled in real time, without physical access to the machine.
  • OpenRGB
  • SSH
  • X11
