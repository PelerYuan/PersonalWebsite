# Peler Yuan · Personal Website

Live at <https://dev.peler.top>.

A static site: plain HTML, CSS and JavaScript, with self-hosted fonts and no build step.

```
index.html        the page
css/style.css     all styles
js/main.js        interactions
assets/           fonts, images, icons, social preview
tools/serve.py    local dev server (python tools/serve.py, then open http://localhost:5500)
tools/og.html     source of assets/og.png
```
